# ML-panic_voice_detector

This is a machine learning model that uses the RAVDESS Emotional Speech Dataset that contain emotions in the audio file like-Neutral, Happy, Sad, Angry, Fear and provides the message if the voice is in normal tone or in panic
To run this code, Go to command in the code dirctory and type python live_predict.py and enter then in the default code you can add a voice files path to predict if it is panic voice or normal voice or you can chnge the funtion and make it live voice tester
